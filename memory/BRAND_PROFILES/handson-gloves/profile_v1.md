## Caveats for downstream

- 5 SKUs only — fully coverable by image hash, but importer-counterfeiters can source visually similar gloves from adjacent factories in China. **Silhouette match alone is not dispositive**; combine with name/brand-mark match.
- D858,906 covers **ornamental design** — useful for visual copies, less useful for gloves that perform similar function with a different aesthetic.
- Manufacturing-in-China is the brand's own statement (per public press). It does not weaken the trademark or patent claims.
